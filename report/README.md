# Report

`final_report.tex` — NeurIPS 2026 format, 10 pages, compiles to `final_report.pdf`.

## Uploading to Overleaf

This folder is self-contained. Upload **all of it** (or zip it first):

```
report/
  final_report.tex      <- the paper; set this as the main document
  neurips_2026.sty      <- style file (already here)
  figures/              <- all 12 figures referenced by the paper
  checklist.tex         <- NeurIPS checklist template (unused, optional)
  neurips_2026.tex      <- original template (unused, optional)
```

In Overleaf: New Project -> Upload Project -> select the zip, then set
`final_report.tex` as the main document. No package installation is needed
beyond what Overleaf ships by default (`neurips_2026`, `booktabs`, `subcaption`,
`multirow`, `graphicx`, `amsmath`, `hyperref`).

## Compiling locally

```powershell
cd report
pdflatex final_report.tex
pdflatex final_report.tex     # second pass resolves cross-references
```
